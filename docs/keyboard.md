# Keyboard shortcuts

## Control panel

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Play or pause |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Back to the start |
| <kbd>Ctrl</kbd>+<kbd>←</kbd> / <kbd>Ctrl</kbd>+<kbd>→</kbd> | Previous / next chapter |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save now |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>6</kbd> | Jump to a page |
| <kbd>F5</kbd> | Bring the prompter to the front |
| <kbd>F11</kbd> | Toggle prompter full screen |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / redo in the editor |

Panel shortcuts use <kbd>Ctrl</kbd> so that plain letters keep working while you
are typing a script.

## Prompter window

These apply when the prompter window has focus.

| Keys | Action |
|---|---|
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Play or pause |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Faster / slower |
| <kbd>←</kbd> / <kbd>→</kbd> | Nudge back / forward two lines |
| <kbd>R</kbd> | Back to the start |
| <kbd>Esc</kbd> | Leave full screen, or rewind |
| <kbd>F11</kbd> | Toggle full screen |
| Mouse wheel | Faster / slower |
| <kbd>Ctrl</kbd> + wheel | Scrub through the script |

Drag the strip along the top of the prompter to move the window; drag the
bottom-right corner to resize it. The rest of the surface is not a drag handle,
so you cannot knock the window out of position by mis-clicking during a read.

## Progress bar

| Keys | Action |
|---|---|
| Click anywhere | Jump to that point |
| <kbd>←</kbd> / <kbd>→</kbd> | Step by 1% |
| <kbd>Shift</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Step by 5% |
| <kbd>Home</kbd> / <kbd>End</kbd> | Start / end |

## Global shortcuts

Turned **off** by default. When enabled on the Settings page, <kbd>Space</kbd>
and <kbd>R</kbd> control the prompter from any application. See
[privacy.md](privacy.md) for what that involves.
